# ІНСТРУКЦІЯ ДО ЛАБОРАТОРНОЇ РОБОТИ №1 (Час виконання на парі: 5-7 хв)

### Крок 1. Підготовка каталогів на ВМ
1. Скопіюйте вміст папки `Pliki_do_skopiowania` на диск D у каталог:
   `D:\Studenci\Cw_01\3ID11B_01\`
   *(Переконайтеся, що папки `historia/`, `ssl/`, `error/`, `meble/`, `meble80/`, `meble443/`, `auta/`, `auta80/` успішно скопійовані).*

---

### Крок 2. Генерація сертифікатів SSL (ВИКОНУЄТЬСЯ ДО ТЕСТУ КОНФІГУРАЦІЇ!)
1. Відкрийте командний рядок CMD від імені адміністратора.
2. Виконайте команду генерації 2048-бітного ключа та сертифіката (якщо файлів ще немає):
   ```cmd
   cd D:\Studenci\Cw_01\3ID11B_01\ssl
   openssl req -new -newkey rsa:2048 -nodes -keyout meble.key -out meble.csr -subj "/C=PL/ST=3ID11B/L=s097882-s097889/O=Politechnika/CN=www.meble.pl"
   openssl x509 -req -days 365 -in meble.csr -signkey meble.key -out meble.crt
   ```
   *(Примітка: якщо файли `meble.crt` та `meble.key` вже створені, цей крок можна пропустити).*

---

### Крок 3. Оновлення конфігурації Apache (`httpd.conf`)
1. Відкрийте файл `D:\cw_01\httpd.conf` у Notepad++ або звичайному Notepad.
2. Зверніть увагу на директиви `Listen`:
   - Якщо в базовому `httpd.conf` уже є `Listen 8080`, рядок `Listen 8080` у фрагменті можна закоментувати (`#Listen 8080`).
   - Якщо вже є `Listen 443`, рядок `Listen 443 https` у блоці SSL також закоментуйте, щоб уникнути конфлікту портів.
3. Прокрутіть у самий кінець файлу `httpd.conf`.
4. Скопіюйте вміст файлу `httpd_append.conf` і вставте в кінець `httpd.conf`.
5. Збережіть файл (`Ctrl + S`).

---

### Крок 4. Перевірка синтаксису конфігурації
1. У командному рядку CMD виконайте перевірку:
   ```cmd
   httpd -t -f D:\cw_01\httpd.conf
   ```
   **Результат повинен бути:** `Syntax OK`.

---

### Крок 5. Перезапуск сервера Apache
1. На робочому столі в папці `student` клікніть правою кнопкою миші на ярлик зупинки/запуску Apache і виберіть:
   **«Uruchom jako administrator»** (або через консоль: `httpd -k restart`).

---

### Крок 6. Перевірка та зняття скріншотів для звіту
Відкрийте браузер Google Chrome і послідовно перевірте всі ресурси:
1. `http://www.meble.pl` -> Відкривається сайт `meble` на порту 80 (директива `DirectoryIndex start.html`).
2. `http://www.meble.pl:8080` -> Відображається dynamic autoindexing каталогу `meble80` із шапкою команди (`naglowek.html`), підвалом (`stopka.html`) та фотографією `foto.jpg`.
3. `http://www.meble.pl/status` -> Відкривається сторінка стану сервера (`mod_status`).
4. `https://www.meble.pl` -> Відкривається шифрований сайт `meble443` (перегляньте властивості сертифіката: `CN=www.meble.pl`, `ST=3ID11B`).
5. `http://www.auta.pl` (та `http://www.auta.pl:8080`) -> Вимагає логін і пароль Basic Auth: введіть `st` / `st` (з `hasla.has`).
6. `http://www.meble.pl/nieistnieje.html` -> Відображається власна сторінка помилки 404.
7. Відкрийте `D:\Studenci\Cw_01\3ID11B_01\historia\p.log` у блокноті — перевірте, чи записалися логи переходів.
