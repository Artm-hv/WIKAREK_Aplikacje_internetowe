# ІНСТРУКЦІЯ ДО ЛАБОРАТОРНОЇ РОБОТИ №1 (Час виконання на парі: 5-7 хв)

### Крок 1. Підготовка каталогів на ВМ
1. Скопіюйте вміст папки `Pliki_do_skopiowania` на диск D у каталог:
   `D:\Studenci\Cw_01\3ID11B_01\`

### Крок 2. Оновлення конфігурації Apache
1. Відкрийте файл `D:\cw_01\httpd.conf` у Notepad++ або звичайному Notepad.
2. Прокрутіть у самий кінець файлу.
3. Зверніть увагу: якщо в базовому `httpd.conf` уже є директива `Listen 8080`, рядок `Listen 8080` в блоці конфігурації можна закоментувати або пропустити, щоб уникнути попередження Apache.
4. Скопіюйте вміст `httpd_append.conf` і вставте в кінець `httpd.conf`. Збережіть файл (`Ctrl + S`).
5. Перед перезапуском можна перевірити синтаксис: `httpd -t -f D:\cw_01\httpd.conf` (має бути Syntax OK).

### Крок 3. Генерація сертифікатів SSL (1 хвилина)
1. Відкрийте командний рядок CMD від імені адміністратора.
2. Виконайте команду:
   ```cmd
   cd D:\Studenci\Cw_01\3ID11B_01\ssl
   openssl req -new -newkey rsa:2048 -nodes -keyout meble.key -out meble.csr -subj "/C=PL/ST=3ID11B/L=97882-97889/O=Politechnika/CN=www.meble.pl"
   openssl x509 -req -days 365 -in meble.csr -signkey meble.key -out meble.crt
   ```
   *(Примітка: якщо сертифікати вже лежать у папці ssl, цей крок можна пропустити або перезапустити скрипт generate_ssl.bat).*

### Крок 4. Перезапуск сервера Apache
1. На робочому столі в папці `student` клікніть правою кнопкою миші на ярлик зупинки/запуску Apache і виберіть:
   **«Uruchom jako administrator»** (або через консоль: `httpd -k restart`).

### Крок 5. Перевірка та скріншоти (Win + Shift + S)
Відкрийте браузер Google Chrome і відкрийте вкладки:
1. `http://www.meble.pl` -> Відкривається сайт meble на порту 80.
2. `http://www.meble.pl:8080` -> Відображається список файлів із шапкою команди (Hizhovskyi & Namachynskyi) та підвалом.
3. `http://www.meble.pl/status` -> Відображається сторінка Apache Server Status (mod_status).
4. `https://www.meble.pl` -> Відкривається зашифрована версія meble443. Перегляньте сертифікат: State=3ID11B, Locality=97882-97889.
5. `http://www.auta.pl` -> З'являється вікно логіну та паролю: введіть `st` / `st`.
6. Відкрийте `D:\Studenci\Cw_01\3ID11B_01\historia\p.log` у блокноті — перевірте, чи записалися логи переходів.

### Крок 6. Запакувати архів
Створіть ZIP-архів папки `3ID11B_01` із назвою:
`pti_01_3ID11B_01.zip` (або `pti_01_3ID11B_97882_97889.zip`).
Вставте скріншоти у файл `Sprawozdanie_Lab_01.docx` і здайте роботу викладачу!
