### 1.3. Стиль коду, архітектурні конвенції та специфіка викладача
Аналіз 18 каталогів із прикладами кодів викладача (`03-Kody_wyklady/`) виявляє характерні патерни, конвенції та технологічні пріоритети:

1. **Кодування символів (Character Encodings):**
   * В історичних скриптах викладача зустрічаються оголошення `iso-8859-2` та `windows-1250` (наприклад, у старих HTML-формах `05 - pisanie stron/a6.html` або сокетах `15 - php socket`).
   * **Сучасний стандарт курсу:** Усі файли коду (PHP, HTML, CSS, JS, XML, SQL) повинні зберігатися у кодуванні **UTF-8 (без BOM)**, а веб-сторінки містити явний заголовок:
     * HTML: `<meta charset="utf-8">` або `<meta http-equiv="Content-Type" content="text/html; charset=utf-8">`
     * PHP: `header('Content-Type: text/html; charset=utf-8');`
     * XML: `<?xml version="1.0" encoding="UTF-8"?>`
   * **Регулярні вирази для польської мови:** У скрипті `11 - polskie litery/sk2.php` викладач демонструє обов'язкове використання модифікатора `u` (PCRE UTF-8) для коректної валідації польських діакритичних знаків:
     ```php
     preg_match('/^[a-zA-ZąćęłńóśźżĄĆĘŁŃÓŚŹŻ\s]+$/u', $tekst)
     ```

2. **Підходи до роботи з базами даних (MySQL / MariaDB):**
   * Викладач розглядає три інтерфейси доступу:
     1. Procedural MySQLi (`mysqli_connect()`, `mysqli_query()`, `mysqli_fetch_row()`, `mysqli_select_db()`) — найбільш поширений у швидких прикладах лекцій (`12 - php bazy danych/01 - Skrypty`).
     2. OOP MySQLi (`$conn = new mysqli($host, $user, $pass, $db); $result = $conn->query(...)`) — використовується в повнофункціональних проєктних прикладах порталів (`12 - php bazy danych/05 - Przyklad/a1.php`–`a6.php`).
     3. PDO (`new PDO("mysql:host=localhost;dbname=test", $user, $pass)`) — теоретичний розгляд у Лекції 12.
   * **Стандарт викладача для веб-додатків:** Відокремлення конфігурації підключення до БД в окремий файл (`konfig.php` або `a.conf`, що парситься через `parse_ini_file('a.conf', true)`). Запобігання SQL-ін'єкціям через `$conn->real_escape_string()` або приведення типів (`(int)`, `floatval()`).

3. **Робота з файловою системою та лічильниками:**
   * Робота з файлами базується на класичних функціях `fopen()`, `fgets()`, `fputs()`, `fread()`, `fclose()`, `file_exists()`.
   * **Обов'язкове блокування файлів (`flock`):** У скриптах `09 - php pliki/sk_05.php` реалізовано патерн конкурентного доступу до файлів лічильників та логів через блокування `flock($fp, LOCK_SH)` (shared lock для читання) та `flock($fp, LOCK_EX)` (exclusive lock для запису) з обов'язковим звільненням `flock($fp, LOCK_UN)`.
   * **Завантаження файлів (`$_FILES`):** Обов'язкова перевірка `is_uploaded_file($_FILES['...']['tmp_name'])`, валідація розміру (`$max_rozmiar`), переміщення через `move_uploaded_file()`.

4. **Генерація динамічної графіки (GD Library):**
   * Використання розширення GD: створення полотна `imagecreate($w, $h)` або `imagecreatetruecolor($w, $h)`, розподіл палітри кольорів `imagecolorallocate()`, прозорість `imagecolortransparent()`, геометричні примітиви (`imagefilledrectangle`, `imagefilledellipse`, `imagepolygon`), рендеринг шрифтів (`imagestring`, `imagettftext`), відправка правильного MIME-типу `header("Content-type: image/png")` або `image/gif`, очищення пам'яті `imagedestroy()`.
   * **Механізм CAPTCHA:** Реалізація у `16 - php grafika/02-CAPTCH/captcha.php` через генерацію випадкового рядка, запис контрольного значення в `$_SESSION['captcha']`, накладання ліній шуму `imageline()` та виведення спотвореного тексту.

5. **Архітектура XML та концепція 3NF в XML:**
   * **Найсуворіша теоретична вимога викладача:** У Лабораторній 6 база даних XML повинна бути строго в **третій нормальній формі (3NF)**!
   * Реалізація 3NF в XML за зразком викладача (`19 - XML/03 - Normalizacja` та `19 - XML/06 - Przyklad/Pracownicy.xml`):
     * Відмова від надлишкового вкладення повторюваних сутностей.
     * Оголошення DTD-схеми безпосередньо всередині XML (`<!DOCTYPE baza [ ... ]>`).
     * Використання спеціальних типів атрибутів **`ID`** (унікальний ідентифікатор запису) та **`IDREF`** (зовнішній ключ, що посилається на `ID` базової таблиці):
       ```xml
       <!ATTLIST stanowisko id ID #REQUIRED>
       <!ATTLIST pracownik id ID #REQUIRED>
       <!ATTLIST pracuje id ID #REQUIRED>
       <!ATTLIST pracuje pracownik IDREF #REQUIRED>
       <!ATTLIST pracuje stanowisko IDREF #REQUIRED>
       ```
   * Обробка XML в PHP виконується через **SimpleXML** (`simplexml_load_file()`, `xpath()`, `addChild()`, `addAttribute()`, `asXML()`).

6. **Генерація PDF (Бібліотека FPDF):**
   * У завданнях, що вимагають експорту звітів у PDF (Лаб 5, тема 8), викладач використовує класичну процедурну OOP-бібліотеку **FPDF 1.8x** (`13 - php programowanie obiektowe/fpdf/fpdf.php`). Основні методи: `new FPDF()`, `AddPage()`, `SetFont('Arial', 'B', 14)`, `Cell($w, $h, $text, $border, $ln, $align)`, `Output()`.

### 2.1. Каталог `03 - serwer http` (Конфігурація веб-серверів)
